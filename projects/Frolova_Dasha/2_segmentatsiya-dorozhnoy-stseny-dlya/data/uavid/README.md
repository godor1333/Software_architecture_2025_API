# Проверка на UAVid

UAVid — набор кадров с беспилотника с пиксельными масками: https://uavid.nl/. Правообладатель распространяет набор под CC BY-NC-SA 4.0. Скачайте изображения и разметку с официального сайта и сохраните структуру `sequence/Images/*.png` и `sequence/Labels/*.png` в этой папке.

Из корня проекта выполните:

```powershell
python -X utf8 evaluate_uavid.py --data-dir data/uavid --limit 100
```

Потребуются доступные веса `nvidia/segformer-b0-finetuned-cityscapes-1024-1024`, PyTorch и Transformers. Скрипт вычисляет pooled IoU для дороги, автомобилей и людей, записывает хеши файлов и метрики в `artifacts/uavid_metrics.json`. Он не сообщает отдельные показатели разметки и общих препятствий: соответствующей разметки UAVid нет. До реального запуска значения не считаются подтверждёнными.
